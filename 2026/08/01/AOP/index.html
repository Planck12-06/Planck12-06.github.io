AOP 概述

AOP：Aspect Oriented Programming（面向切面编程、面向方面编程），面向切面编程就是面向特定方法编程。

优势

优势 说明
减少重复代码 不需要在业务方法中定义大量重复性代码，只需将重复代码抽取到 AOP 程序中即可
代码无侵入 基于 AOP 实现业务功能时，对原有业务代码无任何侵入，无需修改业务代码
提高开发效率 通用逻辑统一管理，减少重复劳动
维护方便 修改通用逻辑只需调整一处

核心概念

概念 英文名 说明
连接点JoinPoint可以被 AOP 控制的方法（暗含方法执行时的相关信息）
通知Advice重复的逻辑，即需要增强的功能代码
切入点PointCut匹配连接点的条件，通知仅会在切入点方法执行时被应用
切面Aspect切入点 + 通知的组合
目标对象Target通知所应用的对象

Spring AOP 通知类型

注解 名称 说明
@Around环绕通知此注解标注的通知方法在目标方法前、后都被执行
@Before前置通知此注解标注的通知方法在目标方法前被执行
@After后置通知此注解标注的通知方法在目标方法后被执行，无论是否有异常都会执行
@AfterReturning返回后通知此注解标注的通知方法在目标方法后被执行，有异常不会执行
@AfterThrowing异常后通知此注解标注的通知方法发生异常后执行

通知示例

切入点复用

由于每一个注解都写了相同的切点表达式，可以将切点表达式抽取到一个方法中，再使用 @PointCut 注解引用这个切点表达式。

通知顺序

在不同切面类中，默认按照切面类的类名字母排序：

  • 目标方法前的通知方法：字母排名靠前的先执行
  • 目标方法后的通知方法：字母排名靠前的后执行

想控制通知的执行顺序有两种方式：

  1. 修改切面类的类名（这种方式非常繁琐、而且不便管理）
  2. 使用 Spring 提供的 @Order 注解（推荐）

切点表达式

作用

主要用来决定项目中的哪些方法需要加入通知。

常见形式

形式 说明
execution(...) 根据方法的签名来匹配
@annotation(...) 根据注解匹配

execution 切入点表达式

execution 主要根据方法的返回值、包名、类名、方法名、方法参数等信息来匹配。

语法格式

其中带 ? 的表示可以省略的部分。

通配符说明

通配符 含义 示例
*单个独立的任意符号，可通配任意返回值、包名、类名、方法名、一个参数，或包/类/方法名的一部分* com.itheima.service.*Service.*(..)
..多个连续的任意符号，可通配任意层级的包，或任意类型、任意个数的参数com..*Service.*(..)

语法规则

序号 规则 说明
1 访问修饰符可省略 如 public 可省略不写
2 返回值可用 * 代替 表示任意返回值类型
3 包名可用 * 代替 代表任意包（一层包使用一个 *）
4 使用 .. 配置包名 表示此包以及此包下的所有子包
5 类名可用 * 代替 表示任意类
6 方法名可用 * 代替 表示任意方法
7 使用 * 配置参数 表示一个任意类型的参数
8 使用 .. 配置参数 表示任意个任意类型的参数

示例对照表

描述 表达式
省略方法的修饰符号execution(void com.itheima.service.impl.DeptServiceImpl.delete(java.lang.Integer))
使用 * 代替返回值类型execution(* com.itheima.service.impl.DeptServiceImpl.delete(java.lang.Integer))
使用 * 代替包名（一层包使用一个 *）execution(* com.itheima.*.*.DeptServiceImpl.delete(java.lang.Integer))
使用 .. 省略包名execution(* com..DeptServiceImpl.delete(java.lang.Integer))
使用 * 代替类名execution(* com..*.delete(java.lang.Integer))
使用 * 代替方法名execution(* com..*.*(java.lang.Integer))
使用 * 代替参数execution(* com.itheima.service.impl.DeptServiceImpl.delete(*))
使用 .. 代替参数（最常用）execution(* com..*.*(..))

execution 与 @annotation 对比

对比项 execution @annotation
匹配方式根据方法签名（返回值、包名、类名、方法名、参数）匹配根据方法上的注解匹配
灵活性表达式复杂，修改时需调整切面类只需在目标方法上添加/移除注解
可读性表达式较长，不易理解语义清晰，一目了然
维护性业务代码与切面耦合度高业务代码与切面解耦
适用场景批量匹配固定模式的方法灵活选择需要增强的方法
推荐程度适合简单场景**推荐使用**（企业开发主流）

连接点 JoinPoint

在 Spring 中用 JoinPoint 抽象了连接点，通过它可以获得方法执行时的相关信息，如目标类名、方法名、方法参数等。

通知类型 连接点类型 说明
@Around ProceedingJoinPoint 必须使用此类型，才能调用 proceed() 执行原始方法
其他四种通知 JoinPoint 使用 JoinPoint 类型即可（ProceedingJoinPoint 是其子接口）

ThreadLocal

简介

ThreadLocal 并不是一个 Thread，而是 Thread 的局部变量。它会为每个线程提供一份单独的存储空间，具有线程隔离的效果，不同线程之间互不干扰。

常见方法

方法 说明
public void set(T value)设置当前线程的线程局部变量的值
public T get()返回当前线程所对应的线程局部变量的值
public void remove()移除当前线程的线程局部变量

应用场景

在同一个线程/同一个请求中进行数据共享时，就可以使用 ThreadLocal。
