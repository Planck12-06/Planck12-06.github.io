Spring Task 定时任务

Spring Task 是 Spring 框架提供的任务调度工具，可以按照约定的时间自动执行某个代码逻辑。

特点

特点 说明
轻量级 无需引入额外依赖，Spring Boot 已内置
简单易用 通过注解即可配置定时任务
Cron 表达式 支持灵活的时间调度规则

Cron 表达式

Cron 表达式是一个字符串，用于描述一个时间周期，用于定时任务的触发时间配置。

组成格式

字段 取值范围 允许的特殊字符
秒（Seconds）0 ~ 59, - * /
分（Minutes）0 ~ 59, - * /
时（Hours）0 ~ 23, - * /
日（Day of Month）1 ~ 31, - * ? / L W C
月（Month）1 ~ 12 或 JAN ~ DEC, - * /
周（Day of Week）1 ~ 7 或 SUN ~ SAT, - * ? / L C #
年（Year，可选）1970 ~ 2099, - * /

特殊字符说明

字符 含义 示例
*所有值（每...）* 在分字段表示每分钟
?不指定值（仅用于日/周字段，必须有一个为 ?）-
-范围10-15 表示 10 到 15
,列举多个值1,3,5 表示第 1、3、5 个
/递增步长0/5 从 0 开始每隔 5 执行一次
LLast（最后一天/最后一周的某天）L 月最后一天
WWorkday（最近的工作日）15W 最近工作日到 15 号
#第几周的星期几6#3 第 3 周的周五

常用表达式示例

Cron 表达式 含义
0 0 9 * * ?每天上午 9 点整
0 0 9 * * MON-FRI周一至周五上午 9 点整
0 0 0 1 * ?每月 1 号零点
0/5 * * * * ?每 5 秒执行一次
0 */10 * * * ?每 10 分钟执行一次
0 30 8,18 * * ?每天 8 点半和 18 点半
0 0 9 12 10 ?每年 10 月 12 日上午 9 点整
0 0 9 L * ?每月最后一天上午 9 点整

WebSocket 协议

WebSocket 是基于 TCP 的一种新的网络协议，实现了浏览器与服务器全双工通信——浏览器和服务器只需要完成一次握手，两者之间就可以创建持久性的连接，并进行双向数据传输。

WebSocket 与 HTTP 协议对比

对比项 HTTP 协议 WebSocket 协议
连接方式短连接长连接
通信模式单向（请求-响应模式）双向通信（基于帧的协议）
底层协议TCPTCP
适用场景常规 Web 请求实时消息推送、即时通讯
